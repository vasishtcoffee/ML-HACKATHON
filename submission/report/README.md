# Report evidence

`PathSnap_Technical_Report.pdf` is the consolidated delivered report. Its metrics,
figures and tables are generated by `scripts/build_report.py` from measured CSVs,
not manually filled numbers.

For a new run, capture fresh screenshots after `scripts/capture_evidence.py`
starts the final-model API at `http://127.0.0.1:8765`:

1. Open the UI, Connect, select a trip and Reconstruct route. Save an actual
   screenshot as `results/screenshots/working_ui.jpg`.
2. Serve `results/maps` locally and open `development_00000009.html`. Check the
   GPS, road, supplied reference and predicted route layers. Save the actual map
   view as `results/screenshots/development_map.jpg`.
3. On the receiving machine, run `python scripts/show_server_evidence.py` in a
   terminal. It sends a live HTTP request and prints the response summary and
   actual receiving Uvicorn logs. Save the actual terminal screenshot as
   `results/screenshots/server_evidence.jpg`.
4. Run `python scripts/build_report.py`. Render the PDF and inspect every page
   for clipped tables, overlaps and readable figures before packaging.

The delivered screenshots are real local executions. They are not presented as
a physical two-laptop LAN demonstration or a reserved-evaluator result.

For this delivery, browser control became unavailable after the integration UI
screenshot, and native Terminal access was rejected by the computer-use safety
tool. `scripts/export_report_evidence.py` exports the actual Folium geometry and
renders the real server-log evidence. Their types are explicitly disclosed in
the report and EVIDENCE_PROVENANCE.json. They do not claim to be native terminal
screenshots. The original live integration UI screenshot is retained.
